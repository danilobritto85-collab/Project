name: Karate special sequences
description: Consent flow for the special scenes of Karate Blonde and Karate Ebony.
---

The special sequences for Karate Blonde and Karate Ebony must start only after the player accepts an optional prompt. Refusal should continue with ordinary defeat, and the player can stop an accepted scene.

**Why:** The user explicitly chose an accept-or-decline challenge for the karatekas' special sequences.

**How to apply:** Keep the consent prompt ahead of any special-scene animation or effects, and provide a clear decline and exit action.
