---
name: Four-armed boss
description: The new elite boss’s selection and optional ending rules.
---

The four-armed boss is a single selectable opponent. Her multi-panel kneeling, bowing, and foot-kissing ending is always optional: show an accept/decline prompt before it begins, and allow the player to stop it. Declining uses the ordinary defeat scene; the Defeeated preview must preserve the fight state and HP.

**Why:** The user chose an explicit opt-in scene rather than an automatic ending.

**How to apply:** Keep the same consent gate for combat defeats and defeat previews; never start the special panels automatically.
