name: Fight configuration
description: User requirements for opponent quantities and roster selection.
---

Allow freely chosen quantities for every opponent category, including multiple Roxys. Do not impose fixed per-category gameplay caps.

**Why:** The user requested “deixe eu adicionar quantos personagens quiser.”

**How to apply:** Provide direct integer entry as well as increment/decrement controls, apply the chosen counts in the actual fight, and warn about performance with very large rosters.
